# Virtual-Console-Overlay
A recreation of the 3DS Virtual Console menu for RetroArch.

Currently tailor made for the MagicX Zero40's 800x480 resolution.

# Features

Recreates the pause menu on the 3DS Virtual Console.

The intent was to be to engage in RetroArch's features via touch without having to into the RA menu.

Touching the left / right half of the top screen will slow down / fast forward the game.

Recommended that you change the on-screen notification vertical postion to 0.560 as by default the overlay will cover the text.
